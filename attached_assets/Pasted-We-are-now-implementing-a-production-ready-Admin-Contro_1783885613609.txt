We are now implementing a production-ready Admin Control Panel for the Vigyanics website.

IMPORTANT:
This should NOT be a simple CRUD page.

Build it like a real enterprise e-commerce admin dashboard.

========================================
AUTHENTICATION
========================================

Create Role Based Authentication.

Roles:

1. Customer
2. Admin
3. Super Admin

Customers can register normally.

Admins CANNOT register through the website.

Only Super Admin can create new Admin accounts.

Create separate authentication.

Customer Login

/signup
/login

Admin Login

/admin/login

If someone without admin privileges tries accessing /admin they should automatically be redirected.

SECURITY
========================================

Protect every admin route.

Middleware should verify role.

Customers should never access admin pages.

Unauthorized users should receive Access Denied.

Use JWT or secure session authentication.

Passwords must be hashed.
